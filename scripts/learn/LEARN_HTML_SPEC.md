# learn.html（IT上場企業 1000本ノック）の仕様 — 実装者向け

目的：上場IT企業（約790社）を「誰に・何を・どうやって」「お金の流れ」で頭に叩き込むための暗記ページ。IRライブラリ（`index.html`）と同じリポジトリ・同じデザイン規約で、`learn.html` 1ファイル（HTML＋CSS＋JS、外部ライブラリなし）として作る。GitHub Pages で配信され、スマホでも使う。

## デザイン規約（厳守）
- 書体 `"BIZ UDPGothic","BIZ UDPゴシック",sans-serif`。本文12px・タイトル（h1）20px
- 色は次の5色＋白のみ：`#D0D0CE`（ライトグレー）`#080808`（黒）`#696965`（ミディアムグレー）`#FF0000`（赤）`#78600C`（ダークオリーブ）`#FFFFFF`（背景と黒地の抜き文字だけ）。これ以外の色コード・色名（`#f6f6f5` のような薄色も）を使わない。濃淡が要るときは `opacity` か上記色の実線・破線・太さで表す
- 既存 `index.html` の `:root` 変数名（`--gray-l --black --gray-m --red --olive`）とクラスの雰囲気（角丸4px・1px枠・`.copybtn`）を踏襲する
- 数値は半角・カンマ区切り。金額は百万円（時価総額は億円）に丸めて単位を付ける。年は西暦
- スマホ幅（375px）で横スクロールが出ないこと。左右の余白16px

## データ（すべて `data/` から fetch。相対パス）
| ファイル | 内容 | 使う項目 |
|---|---|---|
| `companies.json` | 会社一覧（配列） | code・name（正式商号）・display・houjin（法人番号）・market・edinet・src |
| `finance.json` | 時価総額（yfinance・日次） | `[code].mcap`（円）。`rev` は有報が無い社の補完用 |
| `fin.json` | 有報の財務（年1） | `[code].sales`・`op`（円）・`scope`（連結/個別）・`standard`・`fy_end`・`url`（EDINET閲覧）・`segments` |
| `profiles.json` | 本文（事業ごと） | `scripts/learn/SCHEMA.md` のとおり |
| `documents.json` | 開示と要約（配列） | code・date・kind・title・url・summary・ma |
| `meta.json` | 更新日時 | updated |

- 営業利益率 ＝ op ÷ sales（%・小数1桁）。`fin.json` に無い社は `finance.json` の `rev` を売上として使い、営業利益は「－」。表示の横に出典ラベルを付ける（「有報」／「yfinance」）
- `profiles.json` に無い社、または `status.body` が `pending` の社は、骨格だけ（または「未作成」）を表示する。ページが壊れないこと

## 画面
1ページで3つの見方を切り替える（上部のタブ）。URLのハッシュに状態（タブ・絞り込み・開いている社）を持ち、リロードしても戻れること。

### A. 一覧
- **検索**：社名・表示名・証券コード・法人番号・事業名・用語（glossary の term）を部分一致
- **絞り込み**（横並び・スマホでは折りたたみ）：
  - 区分（IT01〜IT11・非IT）：チェックボックス複数。既定は「非IT」だけオフ（放送・通信キャリア等は隠す）。切替「主類型で見る／事業のどれかに含む」
  - 主な顧客（大企業・中小企業・個人・官公庁・公共）、課金型（6種）、業界特化（テキスト部分一致）、市場（プライム・スタンダード・グロース）
  - 本文の状態（作成済み／未作成）、読了（未読のみ／すべて）
  - **数値の範囲**：売上（百万円）・営業利益（百万円）・営業利益率（%）・時価総額（億円）の4組の下限・上限入力
- **並べ替え**：時価総額・売上・営業利益・営業利益率・証券コード・社名。昇降切替。既定は時価総額の降順
- **区分でまとめる**トグル：主類型ごとに見出し行（区分名・社数・小計の売上）を挟んで表示
- **行**：読了チェック／社名（クリックでコピー）／法人番号（クリックでコピー）／市場／主類型バッジ（＋副類型）／売上／営業利益／利益率（赤字は赤）／時価総額／事業数／本文の状態。行クリックで B の1社カードを開く
- 件数表示「表示 n 社／全 N 社」。コピー成功時はボタンの文言を1秒だけ「コピー済」にする

### B. 1社カード
- 見出し：表示名（大）・正式商号・証券コード・市場・法人番号（コピーボタン）・EDINET閲覧URL・IRライブラリの該当社へのリンク（`index.html#<code>` が無ければ `index.html` へ）
- `one_liner`
- 財務4つ（売上・営業利益・利益率・時価総額）と決算期末・会計基準・出典ラベル
- **事業ブロック**（businesses の順。share_pct の降順に並べ替えてよい）：
  - 事業名・担当（本体／子会社名）・区分バッジ・顧客／業界特化／課金型のタグ・売上構成比のバー（share_pct。null なら「比率不明」）
  - 誰に／何を／どうやって（3欄）
  - **お金の流れ図**：`money_flow` を SVG で自動描画。players を横一列（スマホでは縦）の箱に、flows を矢印で。`kind:"money"` はダークオリーブの実線＋矢印＋ラベル（what・when）、`kind:"value"` はミディアムグレーの破線。箱・文字は黒。同じ型で全社を描く（図の体裁を会社ごとに変えない）
  - 出典（sources）
- 用語辞書（glossary）：折りたたみ。term を太字、plain を続ける
- **M&Aニーズ**：① `ma_policy.text`（出典つき）② `documents.json` の同社の要約のうち M&A・買収・提携・資本 を含むもの新しい順2件（日付・種別・タイトルをリンク）③ 同社の `kind:"M&A開示"` 新しい順3件（日付・タイトルをリンク）。無いものは「記載なし」
- 読了チェック（大きめ）・一言メモ（textarea・自動保存）
- 前へ／次へ（現在の一覧の並び順で移動）

### C. 暗記モード
- 現在の絞り込み・並び順で山を作る。進捗「k／n」
- **表→裏**：表は社名・市場・財務4つだけ。ボタン「思い出した」またはスペースキーで裏（Bのカードの事業ブロック以降）を開く
- **逆（事業→社名）**：表は one_liner と事業ブロック（社名・子会社名は `■■` に置き換える。簡易な文字列置換でよい）。裏で社名を表示
- 裏を見た後に「覚えた（読了にする）」「まだ」ボタン。→キーで次へ。「まだ」はこの山の最後に回す

### 保存（ブラウザ）
- `localStorage` キー `learn:v1` に `{ read: {code: "YYYY-MM-DD"}, memo: {code: "…"}, settings: {...} }`
- 「書き出し」ボタン：JSONをクリップボードにコピー＋ `learn_progress_YYYYMMDD.json` としてダウンロード。「読み込み」：ファイル選択または貼り付けで取り込み（既存と統合。読了は新しい日付を優先）
- 読み書きは try/catch で包み、使えない環境でもページが動くこと

## 実装上の注意
- フレームワーク・CDN不要。ES2018程度。790社×数事業の描画は仮想化不要だが、一覧の再描画は絞り込みごとに全行を作り直す素直な実装でよい（1秒以内）
- `documents.json` は2MB超。初回に読み、社ごとの索引（Map）を作る
- 文字はすべて `textContent` か適切なエスケープで入れる（要約・タイトルはそのまま innerHTML に入れない）
- `<title>` は「IT上場企業 1000本ノック」。`<meta name="robots" content="noindex, nofollow">` を付ける（index.html と同じ）
- 単一ファイル。CSS・JS はインライン。完成したら `index.html` の見出し付近に `learn.html` への小さなリンク（1行）を足す
- 自社の案件・接触履歴・売り手の実名は一切載せない

## 受け入れ確認（実装者が自分で行い、結果を報告する）
1. ローカルで `python -m http.server` を立てて開き、コンソールにエラーがない
2. 絞り込み・並べ替え・範囲指定・区分でまとめる・コピー・読了・メモ・書き出し／読み込み・暗記モード（表裏・逆）が動く
3. `profiles.json` に無い社や `body: pending` の社を開いても壊れない
4. 375px 幅で横スクロールが出ない
5. ページ内の色コードを機械で抜き出し、5色＋`#FFFFFF`（大文字小文字の違いは可）以外が無いことを確認する（`grep -oiE '#[0-9a-f]{3,6}' learn.html | sort -u`）
